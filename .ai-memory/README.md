# AI Memory System

This is the permanent knowledge base for AI agents working on Kidoro.

## How to use
1. Read `AGENTS.md` first (project constitution)
2. Read only the relevant memory files for your task
3. Never scan the entire repository
4. Update memory files after every change

## Files
| File | When to read |
|------|-------------|
| `project-overview.md` | Always — first read |
| `architecture.md` | Navigation, data flow, state management tasks |
| `folder-structure.md` | Finding files, adding new files |
| `search-index.md` | Quick file lookup |
| `components.md` | Adding/modifying components |
| `coding-standards.md` | Writing new code |
| `dependencies.md` | Adding/removing packages |
| `known-issues.md` | Bug fixes, before debugging |
| `change-log.md` | Understanding recent changes |
| `decision-log.md` | Understanding why things are the way they are |
| `performance.md` | Performance optimization |
| `security.md` | Security audit |
| `todo.md` | Planning future work |

## Rules
- Never delete this folder
- Always update after every task
- Never duplicate information across files
- Keep summaries short — no source code dumps
